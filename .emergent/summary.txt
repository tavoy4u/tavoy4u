<product_requirements>
The user initially requested a complete Android checkers game with Bluetooth multiplayer, using Kotlin and Jetpack Compose, targeting SDK 34 (minSDK 26+). Rules: American Checkers (8x8, dark squares, men diagonally forward, kings omnidirectional, forced/multi-jumps, win by elimination/blockade).
Due to environment limitations, the app shifted to Expo/React Native for cross-platform (Android/iOS/Web) development. Bluetooth Classic was replaced by a **Server-Based WebSocket multiplayer** approach, supporting global play with room codes.
Key game features implemented include:
- **Game Modes**: American Checkers (single-player AI, multiplayer) and Jamaican Checkers (single-player AI, multiplayer).
- **Jamaican Rules**: Flying Kings (kings move multiple squares), Backwards Tek (captures for men), Maximum Tek rule (must tek most pieces), Hoof rule (penalizing unmade teks, with two specific scenarios), and Multi-Tek Chains (forced continuous teks).
- **Game Board**: Initially 2D, then isometric/angled 3D, and finally **full 3D rendering using Three.js**.
- **Piece Design**: Custom game piece class selection (Jamaican, European, Dragon Ball Z, Sailor Moon) with placeholder 2D/3D sprites. The DBZ class has been integrated with specific images for men (Goku) and kings (Super Saiyan Goku).
- **UI/UX**: Touch-friendly UI, game state persistence.
- **Backend**: FastAPI with a MongoDB database, supporting WebSocket for real-time game state synchronization and room management, including different game modes (American/Jamaican) and class selection.
</product_requirements>
