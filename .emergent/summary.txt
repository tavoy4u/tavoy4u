<product_requirements>
The application is a cross-platform Checkers game, initially targeting Android/Kotlin but implemented with Expo/React Native. It features multiplayer (now polling-based REST API due to WebSocket issues) and single-player AI modes for both American and Jamaican Checkers. Jamaican rules include Flying Kings, Backwards Tek, Max Tek, and the Hoof rule. The game board renders in full 3D using Three.js, with dynamic camera perspectives (e.g., black player view rotated). Core features include player name input, a persistent leaderboard tracking wins/losses, and an 'About' section detailing the maker (Shaune Forrest) and company (CSWP Games). The UI is enhanced with animated 3D space backgrounds for both the home and game screens. A game piece class selection system with custom 3D models was implemented but later entirely removed.
